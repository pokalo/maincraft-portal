⛏ MainCraftPortal

Один клик — и твой Minecraft сервер доступен друзьям

О проекте

MainCraftPortal — десктопное приложение для Windows и Linux, которое автоматически:

  • Скачивает и запускает Minecraft сервер нужной версии
  • Создаёт публичный туннель через playit.gg
  • Показывает адрес — копируешь и скидываешь друзьям
  • Работает с пиратскими клиентами (online-mode=false)
  • Никаких настроек, портов, accounts — всё само

Как использовать

  1. Скачай и запусти MainCraftPortal.exe
  2. Нажми «Сервер»
  3. Выбери версию Minecraft (по умолчанию последняя совместимая)
  4. Подожди — программа скачает сервер, запустит его и создаст туннель
  5. Скопируй адрес из зелёной панели и разошли друзьям
  6. Нажми «Остановить» когда наигрались

Первый запуск

При первом запуске откроется браузер с сайтом playit.gg:

  1. Подтверди создание агента на сайте
  2. Вернись в приложение — ключ сохранится автоматически
  3. В следующий раз ключ не понадобится

Linux (консоль)

sudo apt install dotnet-runtime-9.0 openjdk-21-jre-headless
git clone https://github.com/pokalo/minecraft-server
cd minecraft-server/MainCraftPortal.CLI
dotnet publish -c Release -r linux-x64 -o publish
./publish/MainCraftPortal

Нажми Ctrl+C для остановки.
